# CRM 按钮规范

所有新功能优先使用 `src/components/ui.tsx` 中的 `Button`，不要为业务页面重新定义高度、内边距或图标尺寸。

## 尺寸

| 尺寸 | 高度 | 使用场景 |
| --- | ---: | --- |
| `sm` | 30px | 表格行操作、卡片内次要操作、紧凑区域 |
| 默认 | 36px | 页面工具栏、表单、抽屉和弹窗底部 |
| `lg` | 44px | 登录、空状态等需要突出显示的主入口 |
| `icon` | 36 × 36px | 关闭、刷新等只有图标的按钮 |

按钮文字不换行；默认图标为 16px，`sm` 图标为 14px。相邻按钮间距统一为 8px。

## 语义

- `primary`：一个操作区最多一个，用于保存、确认、推进等主要动作。
- `default`：编辑、暂停、恢复、回退、取消弹窗等普通动作。
- `ghost`：关闭或不需要容器强调的图标动作。
- `danger`：永久删除或不可逆操作。
- `ui-button--danger-soft`：取消合作等需要警示、但保留数据且可追溯的操作。

## 排列

- 弹窗右侧固定为“取消、主操作”。
- 辅助业务操作放在弹窗左侧，并与右侧操作保持同一高度。
- 同一操作组内不要混用默认和紧凑尺寸。
- 表格中统一使用 `sm`；不要把页面级主按钮塞进表格行。
- 纯图标按钮必须提供 `aria-label` 或 `title`。

## 禁止事项

- 不直接用裸 `<button>` 创建新的常规操作按钮。
- 不在业务页面覆盖按钮的 `height`、`padding`、`font-size`。
- 不用文字换行来容纳按钮；空间不足时让操作组整体换行。
- 不用红色表示可逆的普通操作。
